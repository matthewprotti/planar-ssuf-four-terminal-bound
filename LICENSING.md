# Licensing status

No copyright, patent, or other intellectual-property ownership claim is made
in this repository, and this release grants no open-source or
open-content license. `CITATION.cff` therefore omits its optional `license`
field.

Naming Matthew Protti as the human author is an attribution of authorship,
not a representation about ownership of legal rights. No institutional
affiliation, sponsorship, or institutional ownership is asserted.

A public GitHub repository can be read and forked under GitHub's applicable
terms, but the absence of a repository license means that no additional
permission is granted here for copying, modifying, or redistributing the
contents. Any later licensing decision should be made prospectively in a new,
clearly dated version by a person with authority to grant it.

No-license status is not confidentiality. Making the repository public would
disclose the manuscript, source, data, and verification code to the world,
regardless of whether a reuse license is granted. Publication should therefore
occur only if no patent or trade-secret protection is being preserved for the
released material.

This status note is a release-control safeguard, not legal advice.
